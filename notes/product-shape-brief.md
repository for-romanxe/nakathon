# Crew Health 제품 구조 브리프 (shape, 2026-11-11)

회의 논의용 · 제출물 아님. 제출용 화면은 11/14 09:00 이후 새로 제작.

## 조사에서 가져온 사실
- ISS에서는 Bio-Monitor(캐나다 CSA) 조끼·헤드밴드를 운동·일과·수면 중 최대 48시간 착용하고, 승무원이 기기를 떼어 데이터를 내려받아 지상 의사가 검토한다. 혈압계·산소포화도·심전도 같은 수동 측정도 병행한다. → "착용 → 동기화 → 검토" 리듬이 실제 운영과 같다.
- NASA ExMC는 화성 임무를 위해 Earth-Independent Medical Operations(EIMO)를 준비 중. 재보급·후송 불가, 통신 지연이 자율화의 이유. 임무 단계별 use-case 시나리오로 필요한 기능을 정의한다. ISS는 이미 온보드 임상 의사결정 지원을 받지만 심우주는 더 필요(2025 SpaceOps C2M2).
- 임상 경보 연구: 경보 피로는 "관련 없는 경보가 많을 때" 생긴다. 긴급도별 계층, 워크플로 시점에 맞춘 전달, 무시(override) 시 이유 기록, 근거·논리 노출이 신뢰를 만든다. 낮은 긴급도부터 신뢰를 쌓고 높은 긴급도로 확장(JMIR 2026).
- 건강앱 구조: 탭은 적게, 관리 항목(계정·알림·권한)은 주 내비게이션에서 분리.

## 제품 구조 (한 페이지에 몰지 않음)
좌측 레일 7개 + 상세 페이지. 파일은 화면마다 하나, 공통 CSS·JS, 상태는 localStorage로 페이지 사이에 유지.

1. **오늘** — 상태 배너, 바디(작게), 지표 6 타일, 할 일. (지금 dashboard.html의 뼈대를 줄여서)
2. **몸** — 픽셀 바디 크게 + 부위 목록 + 부위 상세 패널. 부위 → 지표 상세로 이동.
3. **추세** — 지표별 7/30/90일, 기준선 밴드, 이벤트 마커. 지표 상세 페이지.
4. **기록** — 증상 대화(모델이 끼는 유일한 입력), 체크인 설문, 이벤트 목록.
5. **절차서** — 기기 내 문서, 검색, 열람 기록. 설명 속 출처 id가 여기로 링크.
6. **승무원** — CMO 전용. 4명 그리드, 기준선 진행, 지구 전송 큐.
7. **설정** — 기준선 재계산, 민감도, 열람 권한, 전송 창, 모델 정보(버전·메모리). 주 내비게이션과 분리된 느낌으로 맨 아래.
- **이벤트 상세**(별도 페이지): 사실(규칙) · 설명(모델) · 검증(코드) 3단 + 대응 + 공유 + 무시 시 이유 기록.
- **경보 화면**(Warning 전용): 전체 화면, 절차서 첫 단계, CMO 호출, 지구 긴급 큐.
