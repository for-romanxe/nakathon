# 팀 회의록 정리 (2026-11-11 저녁, 녹음 44분)

원본: `~/Downloads/이의동 32.m4a`. 로컬 Whisper(large-v3-turbo)로 전사, 화자 구분 없음. 사람 이름·용어 일부는 오인식(예: "락"=RAG, "다이얼 모델"=다이얼업 모뎀, "QN"=Qwen). 31~40분은 잡담이라 제외. 전사본은 커밋하지 않음(잡담·개인 이야기 포함).

## 논의 요약 (주제별)
1. **진단·처방 범위 (0~1분)**: 진단은 AI 생각이 아니라 데이터 근거로. 약 처방이 들어가면 사람이 한 번 확인하는 휴먼 인 더 루프를 넣자. 구현하면 점수에 유리할 듯.
2. **팀원 대시보드 시연 (1~4분)**: 승무원 목록, 정상은 무색·주의·위험은 빨강, 누르면 상세(수면 평균·정상 범위), AI 판단(위험 / 지상 의료진 연락)과 판단 이유, 최근 3일 판단, 증상 채팅. 처음엔 지표 정의 설명을 넣었다가 "우주비행사는 이미 알 것"이라 뺌. 다른 팀원은 입력·저장·그래프 갱신 구현.
3. **할루시네이션·RAG·검증 루프 (4~8분)**: RAG는 출처를 정확히 하는 것이지 할루시네이션을 없애진 않음. 생성 SLM 뒤에 검사자(심사자) 모델을 두고 RAG 문서와 대조·인과관계 확인하게 프롬프트. 모르면 모른다고. 팀원 데모: "두통+어지러움 → 긴장성 두통 가능성 높음, 진통제 드시고 쉬세요"에서 검사기가 단정 표현과 진통제 권고를 삭제. 다른 대회 경험: 검사자가 근거 부족 판정하면 입력으로 되돌려 10~12회 루프, 그래도 안 되면 근거 부족 출력.
4. **SLM vs 지구 LLM, 통신 (7~11분, 19~24분, 43분)**: 통신이 불가능한 건 아님(ISS 1초 미만, 달 1.3초, 화성 3~22분). 왕복 30분이면 지구 LLM이 진단·처방까지 할 수 있으니, 아침·저녁 배치(저녁에 보내면 아침에 답)로 SLM 역할을 줄이고 LLM을 루프에 넣는 안. 반론: 심리는 즉시성이 필요("지금 죽고 싶다"에 1시간 뒤 답은 의미 없음). 응급은 결국 SLM + 옆 승무원 도움, 응급 키트 문서를 RAG에 추가. 달 뒷면·극지 근처 통신 두절. 손실 아이디어: 같은 값을 100번 보내 다수결. 결론: 통신은 창 단위, 손실은 있지만 규칙적이라 예측 가능, 일부만 도착 가정, 원본은 항상 로컬 보관, 세부는 백엔드에 맡김.
5. **CMO 기록 간소화 (8~10분)**: 우주 안 의료 담당이 매일·매주 식사 등 기록·리뷰. 웨어러블은 수면·혈압 정도라 나머지는 사람이 조사. 매일 AI에 말로 입력은 귀찮으니 30초~1분 양식(수면·수분·식사). 쌓아서 사람별 기록 시스템.
6. **심리 (11~13분, 17~19분, 30분)**: "기분 꿀꿀해" 같은 포괄적 표현을 SLM이 1~10 척도로 바꾸는 번역 역할. 후보로 그림 심리(야매 느낌이라 보류), 표정 인식(어렵지만 구현하면 강력), 군대식 규칙 기반 심리 설문. 아침 인사에서 표정 보고 "안 좋은 일 있었어요?" 묻기.
7. **보안 (14분)**: 아이디·비밀번호는 약함, 얼굴 인증 로그인 아이디어. 심사 기준엔 없음.
8. **데이터 활용 (15~17분)**: 사람별 DB를 SLM이 불러 "6개월 전보다 혈압 상승" 같은 비교. 비행 전 본인 상태 입력. 중력·방사선 데이터는 어떻게 쓸지 미정.
9. **화면 방향 (25~28분)**: "심박이 높다"만으로는 뭘 하라는지 모름 → 해결책을 먼저 쉬운 말로(운동 2시간 30분 → 1시간 조정 + 이유). 팀원 화면: 주의 항목을 누르면 대응이 뜨고 "할 일에 추가"로 개인 할 일에 들어감.
10. **체크인 (28~30분)**: 아침·저녁 두 번. 아침엔 수면 질, 저녁엔 오늘 하루 어땠는지. 귀찮아도 기능은 있는 게 낫다(건너뛰면 되니까). 시작 멘트 중요, 기상 시각 기준 "아침"으로 커스텀.
11. **운영 (17~18분, 39~41분)**: 오늘 명세(기능·인터페이스) 확정 목표, 기획·명세 담당 1~2명 필요. SLM 학습은 명세가 정해지면 오늘부터 시작한다는 발언. 모델 후보 Qwen 4B(약하다는 평), 다른 대회는 11B·33B, 32GB면 11B 가능, 우주 탑재 시 발열.

## 우리 설계와 일치
- 해결책 먼저(오늘의 가이드), 아침·저녁 체크인, 30초 양식, 사람별 기록 누적, 단정 표현·약 권고 삭제, 모르면 보류, 원본 로컬 보관·일부 도착 가정.

## 충돌·미정 (보충 필요)
1. **사전 제작 금지와 "오늘부터 SLM 학습"**: 서울 규칙상 산출물(코드·디자인·슬라이드·영상) 사전 제작 금지, 준비는 허용. 우리 과제용 데이터로 모델을 학습시키는 건 사전 제작으로 볼 여지가 큼. 11/14 08:00 Zoom 전에 운영진 확인 필요. 그 전엔 환경 설치·모델 다운로드·자료 읽기까지만.
2. **SLM과 지구 LLM의 분담**: "즉시 필요한 것(증상 분류·응급·심리)은 기기 안 SLM, 기다려도 되는 것(주간 검토·2차 의견·처방 검토)은 다음 통신 창의 지구 LLM·비행의"로 원칙화하면 두 의견이 합쳐짐.
3. **검증 방식**: 검사자 모델 + 10~12회 루프 vs 우리 코드 검증 5규칙 + 2회 후 보류. 4B에서 1.8초×12회면 20초 이상. 검사자도 모델이라 틀릴 수 있음. 제안: 코드 검사 먼저(숫자·출처·목록·단정 표현), 의미·인과 검사만 검사자 모델, 루프 상한 2~3회.
4. **심리 안전 규칙**: 자해·자살 표현은 흉통처럼 모델과 무관한 규칙으로 즉시 경보(옆 승무원·CMO 호출). 모델은 경보를 올릴 수만 있음. 일상 기분은 NASA BHP처럼 매일 눈금 + 선택적 자유 문장(SLM이 척도로 변환). 그림 심리·표정 인식은 근거·사생활 문제로 확장 과제로.
5. **수분**: 팀원 양식엔 수분이 있음, 조사 결과 NASA 요구사항엔 없음. 저녁 체크인 한 탭(충분히 마셨나요 예/아니오) 같은 절충안 결정 필요.
6. **휴먼 인 더 루프 정의**: 시스템은 약을 권하지 않음. 약 관련 질문이면 "CMO 확인 필요"로 넘기고 CMO 승인 기록. 이게 HITL 구현 지점.
7. **비행 전 기준선**: 14일 기내 기준선에 더해 비행 전 값(OCHMO L-180 등) 입력 → 비교 기준 두 개.
8. **중력·방사선 데이터**: 11/13 공개되는 Resources 탭 데이터 확인 후 결정. 방사선은 누적 선량, 중력은 골밀도·체액 이동·근육 지표로 연결.
9. **모델 크기**: 4B vs 11B. 실행 기기·지연·평가 결과로 결정. 행사 중 같은 질문셋으로 비교.
10. **대시보드 통합**: 팀원 대시보드(승무원 목록·상세·AI 채팅·할 일 추가)와 내 목업을 하나의 명세로. "할 일에 추가"는 채택할 만함.
11. **명세 담당**: 기획·명세 1~2명 지정 안 됨.
12. **보안·얼굴 인증**: 심사 기준 밖. 후순위.
