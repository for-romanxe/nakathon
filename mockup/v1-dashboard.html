처리 흐름 — 코드가 흐름을 쥐고, SLM은 두 칸만

입력이 어떻게 들어가고, 단계마다 무엇이 나오고, 어디서 모델이 끼는지. 상태 판정은 ②에서 끝나고 SLM은 그걸 옮겨 적을 뿐.

{"passed":true,

출력 (화면)

상태 배지 + 수치 카드 + 출처 달린 설명 + 대응 체크리스트 + 검증 5/5 표시. 승무원은 읽고, 체크하고, 필요하면 의료 담당에게 넘긴다. → 3번 화면

검증 실패 · 근거 부족일 때

SLM 문장은 안 보여 준다. "판단 보류" 배지와 ②의 수치만 보여 주고 의료 담당 호출 버튼을 띄운다. 모델이 모르는 걸 아는 척하지 못하게 하는 게 이 칸의 전부. → 3번 화면에서 "검증 실패 상태 보기"
